# AbxHub v0.15.0 — high-risk reconciliation phase

- Expanded the MOH Dec 2025 fluid-restricted critically ill adult guide from 4 to **39 matching injectable anti-infectives** in the current database.
- Fluid-restricted preparation remains a separate ICU minimum-volume overlay; standard MOH antimicrobial dilution remains the baseline preparation source.
- Added source-specific high-risk review cards for vancomycin/TDM, aminoglycosides, polymyxin B, colistin/CMS, amphotericin formulations, prolonged beta-lactam infusion, ceftazidime-avibactam + aztreonam in NDM/MBL CRE, cefiderocol and high-dose tigecycline.
- Added structured amikacin RRT data and a TDM-only renal guard for gentamicin rather than inventing a fixed CRRT interval.
- Added a structured prolonged-infusion matrix for cefepime, ceftazidime, imipenem, meropenem and piperacillin/tazobactam.
- Expanded TDM metadata using current NAG Appendix 1 plus the bundled MSIC ICU reference.
- Added paediatric source-validation across the supplied Blue Book APK and Frank Shann DrugDoses APK; differing doses remain source-specific.
- Added an explicit amphotericin formulation guard: amphotericin B lipid complex is **not** mapped to liposomal amphotericin B.

This remains a pre-v1.0 review build. Local ICU pharmacy/ID sign-off is still required for TDM workflows, aminoglycoside nomograms, CMS/colistin unit conventions, CRRT assumptions and paediatric/neonatal dosing.
