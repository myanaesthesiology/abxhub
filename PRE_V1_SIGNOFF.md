# AbxHub pre-v1.0 sign-off matrix

AbxHub v0.16.0 is **source-reconciled**. It is not yet labelled institutionally validated.

| Domain | Source reconciliation | Local sign-off | v1.0 gate |
|---|---|---|---|
| NAG freshness / national recommendations | Complete for current v0.16 scope | Pending future-update governance | Required |
| Vancomycin AUC/TDM | Reconciled NAG + MSIC | Local Bayesian platform, assay timing, pharmacist/ID workflow pending | Required |
| Aminoglycosides | Reconciled NAG + MSIC + paediatric sources | Local nomogram/TDM workflow pending | Required |
| HD/CRRT | Source-specific rules and guards structured | Local CRRT prescription/effluent assumptions pending | Required |
| Colistin / polymyxin B | Unit/product distinction structured | Local formulary/unit convention pending | Required |
| Amphotericin formulations | Formulation guard structured | Locally stocked product/preparation check pending | Required |
| Prolonged β-lactam infusion | MSIC + MOH dilution layers separated | Local stability/line compatibility policy pending | Required |
| Paediatric/neonatal | Current NAG + Shann + Blue Book layers separated | Paediatric/Neonatal ID/pharmacy review pending | Required |
| Dilution | National MOH standard + Dec 2025 fluid-restricted overlay structured | Local product/brand verification pending | Required |

A future **v1.0** should mean the high-risk rows above have named local clinical/pharmacy review rather than simply more database entries.
